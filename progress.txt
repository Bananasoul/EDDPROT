EDD HSNE — Demo v0 · Journal de progression
============================================

OBJECTIF GLOBAL
---------------
Maquette cliquable (pas de backend réel) destinée à débloquer des ressources
auprès de la direction HSNE et du service IT. Priorité : montrer la
transformation du service chaotique en parcours coordonné.

STACK
-----
- Next.js 16.2.4 (App Router) + React 19 + TypeScript
- TailwindCSS v4 (@theme tokens dans globals.css)
- Recharts (courbes), lucide-react (icônes), clsx + tailwind-merge
- Données mockées en TypeScript (src/lib/mock-data.ts)
- Langue gérée via AppProvider (React Context + localStorage)

POINTS TECHNIQUES À GARDER EN TÊTE
-----------------------------------
- Next.js 16 : TOUS les composants utilisant hooks/state/Context DOIVENT être
  "use client". AppShell, pages dashboard, ScoresTable, PainChart = client.
- Tailwind v4 : couleurs custom via @theme (pas tailwind.config.js).
  Les classes bg-navy, text-clover, etc. sont auto-générées.
- Fonts Google : `@import url(...)` DOIT être AVANT `@import "tailwindcss"`
  dans globals.css (sinon PostCSS rejette).
- Recharts côté SSR émet un warning width/height(-1) inoffensif.
- IDs patients : p001..p007, 5 avec scores complets, 2 en attente T0.
